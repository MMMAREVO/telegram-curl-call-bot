# Бот для тестовых звонков — описание для деплоя

## Что это

Telegram-бот, через который тестировщики запускают звонки голосового бота по кампаниям (Микрозаймы, Лимиты, Узум авто, Кредиты).

Тестировщик нажимает кнопку → бот шлёт запрос (курл) в API кампаний → платформа звонит на номер тестировщика. После звонка бот сам собирает и присылает в чат:

- результат звонка из БД;
- транскрипцию с интентами;
- аудиозапись;
- архив со всеми логами звонка;
- паузы «человек замолчал → бот ответил»: по записи («как слышится») и по логам, с разбивкой по этапам.

Всё это сохраняется в Excel и в папку `call_logs`. Админ может выгрузить отчёт по кампании.

## Что нужно

- Python 3.11 или новее (сейчас работает на 3.14).
- Зависимости — `requirements.txt`: aiogram, httpx, asyncpg, asyncssh, openpyxl, python-dotenv, aiohttp-socks.
- Машина во внутренней сети (или в VPN) и доступ к Telegram.
- Сервер не нужен мощный: бот почти всё время ждёт ответов от других систем. Место на диске растёт из-за аудиозаписей, примерно 1–2 МБ на минуту звонка.

## Куда бот ходит

| Куда | Адрес | Зачем |
|---|---|---|
| Telegram | api.telegram.org (HTTPS) | Сам бот. Если напрямую закрыто — через прокси (`BOT_PROXY` или `HTTPS_PROXY`) |
| API кампаний (iba-dispatcher) | <lab-host>:8080 | Запуск звонка |
| PostgreSQL (лаборатория) | <lab-host>:5432, БД `iba` | Результат звонка, транскрипция, ссылка на запись. Добавление номера тестировщика в кампании |
| Хранилище записей | <lab-host>:8333 | Скачать аудио звонка |
| VictoriaLogs (CPAAS) | <victorialogs-host> (HTTP) | Логи звонка: asr-orch, sfas, sengine, vad, text-lid и др. По ним считаются паузы |
| SSH лаборатории | <lab-ssh-host>:22 | `sudo kubectl logs` пода `iba-app-0` (namespace `iba`) |
| SSH CPAAS | <cpaas-ssh-host>:22 | `sudo kubectl logs` пода `cpaas-studio-0` (namespace `cpaas`) |

## Какие доступы нужны

- **Токен бота Telegram** — от @BotFather.
- **SSH-ключ** на оба сервера (<lab-ssh-host> и <cpaas-ssh-host>), под пользователем, которому разрешён `sudo kubectl logs`. Ключ передаётся отдельно, в архиве с ботом его нет.
- **Пользователь PostgreSQL**, который может:
  - читать `iba.call_attempts` и `iba.campaigns`;
  - добавлять строки в `iba.numbers` (бот добавляет номер нового тестировщика во все кампании со статусом `done`, чтобы платформа сама на него не звонила).
- **Пароль доступа к боту** — придумать самим, его вводят новые пользователи.

## Настройки (.env)

Все настройки лежат в файле `.env` рядом с папкой `bot`. Шаблон — `.env.example`. Главное:

| Настройка | Что это |
|---|---|
| `BOT_TOKEN` | Токен бота. Обязательно |
| `BOT_ACCESS_PASSWORD` | Пароль для новых пользователей. Обязательно — без него бот не запустится |
| `ADMIN_TELEGRAM_IDS` | Telegram ID админов через запятую. Админам доступны новый раунд, тест-планы и выгрузка по всем |
| `BOT_PROXY` | Прокси для Telegram, если нужен (например `http://127.0.0.1:10808`) |
| `CAMPAIGNS_API_BASE` | Адрес API кампаний |
| `PG_HOST`, `PG_PORT`, `PG_DB`, `PG_USER`, `PG_PASSWORD` | Подключение к БД |
| `PG_TABLE`, `PG_TEXT_COLUMN` | Таблица звонков и колонка с транскрипцией (`iba.call_attempts`, `transcribation`) |
| `SSH_HOST`, `SSH_USER`, `SSH_KEY_PATH`, `K8S_NAMESPACE`, `K8S_POD` | Логи лаборатории |
| `SSH2_HOST`, `SSH2_USER`, `SSH2_KEY_PATH`, `K8S_NAMESPACE_2`, `K8S_POD_2` | Логи CPAAS |
| `VLOGS_URL` | Адрес VictoriaLogs. Если оставить пустым — логи оттуда не собираются и паузы не считаются |
| `EXCEL_PATH`, `LOGS_DIR` | Где хранить Excel и папку с файлами звонков (по умолчанию `bot_data.xlsx` и `call_logs`) |

Таймауты (`CALL_COMPLETION_TIMEOUT`, `TRANSCRIPT_TIMEOUT`, `MAX_CALL_SESSION_SECONDS` и др.) можно не трогать.

## Установка и запуск

**Windows** (как сейчас):

1. `setup.bat` — создаст `.venv` и поставит зависимости.
2. Заполнить `.env`, положить SSH-ключ, поправить путь `SSH_KEY_PATH`.
3. `start.bat` — запуск. Окно не закрывать.


## Где лежат данные

- `bot_data.xlsx` — пользователи, все звонки, раунды, тест-кейсы, прогресс. Это **основная база бота**, её надо бэкапить.
- `call_logs/<кампания>/<дата>/` — по каждому звонку: логи, транскрипция, аудио, таблица пауз.

В обоих есть персональные данные (телефоны, голос), в git они не попадают (`.gitignore`).

## Важно

- **Бот должен работать только в одном экземпляре.** Если запустить второй (на другой машине или во втором окне), Telegram выдаёт `Conflict: terminated by other getUpdates request`, и сообщения теряются.
- Пока бот работает, не держать `bot_data.xlsx` открытым в Excel — бот не сможет в него писать.
- Список пользователей бот читает из Excel при старте. Если удалить человека из листа `Users` вручную, доступ пропадёт после перезапуска.
- Секреты (`.env`, SSH-ключ) хранить только на машине с ботом, в git и чаты не выкладывать.
- Логи VictoriaLogs хранятся недолго (около суток–двух), поэтому бот забирает их сразу после звонка.
