УСТАНОВКА TELEGRAM-БОТА НА НОВЫЙ КОМПЬЮТЕР (Windows)
====================================================

Коротко:
  1) установить Python  →  2) распаковать архив  →  3) setup.bat
  →  4) проверить .env и SSH-ключ  →  5) start.bat


----------------------------------------------------
ЧТО ЛЕЖИТ В АРХИВЕ
----------------------------------------------------
  bot\              — код бота
  requirements.txt  — список библиотек, которые нужны боту
  .env              — настройки: токен бота, пароли, адреса серверов
                      (СЕКРЕТНЫЙ файл — никому не пересылайте!)
  .env.example      — пустой шаблон настроек (на случай, если .env нет)
  bot_data.xlsx     — база: пользователи, звонки, тест-планы
  setup.bat         — установка (создаёт и заполняет .venv)
  start.bat         — запуск бота
  ИНСТРУКЦИЯ.txt    — этот файл

Папки .venv в архиве НЕТ и быть не должно: виртуальное окружение
привязано к конкретному компьютеру, его всегда создают заново на месте.
Файл .env начинается с точки. Windows может его не показывать —
включите «Вид → Показать → Скрытые элементы».


----------------------------------------------------
ШАГ 1. УСТАНОВИТЬ PYTHON
----------------------------------------------------
1. Скачайте Python 3.11 или новее: https://www.python.org/downloads/
2. Запустите установщик и ОБЯЗАТЕЛЬНО отметьте внизу галочку
       [x] Add python.exe to PATH
   потом нажмите «Install Now».
3. Проверка: откройте PowerShell (Пуск → «PowerShell») и введите
       python --version
   Должно показать что-то вроде «Python 3.14.5».
   Если пишет «не найдено» или открывается Microsoft Store —
   Python установлен без галочки PATH, переустановите его с галочкой.


----------------------------------------------------
ШАГ 2. РАСПАКОВАТЬ АРХИВ
----------------------------------------------------
Распакуйте архив в любую папку, например D:\bot\
(Правой кнопкой по архиву → «Извлечь всё...»)


----------------------------------------------------
ШАГ 3. СОЗДАТЬ И ЗАПОЛНИТЬ VENV
----------------------------------------------------
Что такое venv: это отдельная папка .venv внутри проекта, куда
ставятся библиотеки только для этого бота. Так они не мешают другим
программам на компьютере, а бот всегда запускается с нужными версиями.
«Заполнить venv» = установить в неё библиотеки из requirements.txt.

ВАРИАНТ А — автоматически (рекомендуется)
    Дважды щёлкните setup.bat.
    Он сам: найдёт Python → создаст .venv → обновит pip →
    установит все библиотеки из requirements.txt.
    Дождитесь надписи «Готово!». Нужен интернет.

ВАРИАНТ Б — вручную, те же шаги по отдельности
    Откройте PowerShell в папке бота (в Проводнике зажмите Shift,
    щёлкните правой кнопкой по пустому месту в папке →
    «Открыть окно PowerShell здесь» / «Открыть в терминале»).
    Затем по очереди:

      1) создать пустое окружение:
            python -m venv .venv

      2) включить его (в начале строки появится (.venv)):
            .venv\Scripts\activate

         Если PowerShell ругается «выполнение сценариев отключено»,
         один раз выполните и повторите activate:
            Set-ExecutionPolicy -Scope CurrentUser RemoteSigned

      3) обновить установщик pip:
            python -m pip install --upgrade pip

      4) заполнить окружение библиотеками:
            pip install -r requirements.txt

      5) проверить, что всё встало:
            pip list
         В списке должны быть aiogram, openpyxl, asyncpg, asyncssh,
         httpx, python-dotenv, aiohttp-socks.

Если pip не может скачать библиотеки (корпоративная сеть с прокси):
    pip install -r requirements.txt --proxy http://адрес_прокси:порт

Если что-то сломалось — просто удалите папку .venv целиком
и повторите этот шаг. Больше ничего она не затрагивает.


----------------------------------------------------
ШАГ 4. ПРОВЕРИТЬ НАСТРОЙКИ (.env) И SSH-КЛЮЧ
----------------------------------------------------
Откройте .env в Блокноте.

1. SSH-ключ. В строках
       SSH_KEY_PATH=C:\Users\<ваше_имя>\.ssh\id_ed25519
       SSH2_KEY_PATH=C:\Users\<ваше_имя>\.ssh\id_ed25519
   указан путь на СТАРОМ компьютере. Скопируйте файл ключа
   id_ed25519 (его передают отдельно, в архиве его нет) на новый
   компьютер, например в C:\Users\<ваше_имя>\.ssh\, и поправьте
   оба пути.

2. Прокси для Telegram. Если Telegram в этой сети открывается только
   через прокси, добавьте строку:
       BOT_PROXY=http://адрес_прокси:порт

3. Администраторы. ADMIN_TELEGRAM_IDS — Telegram ID админов через
   запятую. Меняйте, только если админы другие.

4. Пароль доступа. BOT_ACCESS_PASSWORD — пароль, который бот спрашивает
   у нового пользователя перед регистрацией. Без него бот не запустится.
   Уже зарегистрированные пользователи и админы пароль не вводят.
   После 5 неверных попыток подряд ввод блокируется на 15 минут.

Остальное (адреса серверов, БД) менять не нужно, если компьютер
в той же сети.


----------------------------------------------------
ШАГ 5. ЗАПУСТИТЬ
----------------------------------------------------
Дважды щёлкните start.bat. Окно должно остаться открытым,
в нём пойдут строки логов. Напишите боту /start в Telegram.

Вручную то же самое:
       .venv\Scripts\activate
       python -m bot.main

Остановить бота: закрыть окно или нажать Ctrl+C.
При следующих запусках setup.bat не нужен — только start.bat.


----------------------------------------------------
ВАЖНО
----------------------------------------------------
* Бот должен работать ТОЛЬКО НА ОДНОМ компьютере. Перед запуском на
  новом остановите его на старом. Иначе Telegram выдаёт ошибку
  «Conflict: terminated by other getUpdates request», и сообщения
  теряются.

* Компьютер должен видеть внутреннюю сеть (или быть в VPN):
      API звонков   <lab-host>:8080
      SSH (логи)    <lab-ssh-host> и <cpaas-ssh-host>
      PostgreSQL    адрес из PG_HOST в .env
  Без этого бот запустится, но звонки/логи/транскрипции работать
  не будут.

* Не держите bot_data.xlsx открытым в Excel, пока работает бот —
  иначе бот не сможет в него записывать.

* Чтобы бот не выключался, компьютер не должен уходить в сон:
  Параметры → Система → Питание → «Переходить в спящий режим» = Никогда.


----------------------------------------------------
ЧАСТЫЕ ОШИБКИ
----------------------------------------------------
«python не является внутренней или внешней командой»
    → Python не в PATH. Переустановите с галочкой «Add python.exe to PATH».

«No module named 'aiogram'» (или другой модуль)
    → Бот запущен не из venv или venv не заполнен.
      Запустите setup.bat ещё раз, а бота — через start.bat.

«KeyError: 'BOT_TOKEN'»
    → Нет файла .env рядом с папкой bot, или в нём нет BOT_TOKEN.

«В .env не задан BOT_ACCESS_PASSWORD»
    → Добавьте в .env строку BOT_ACCESS_PASSWORD=<пароль> (см. шаг 4).

«Conflict: terminated by other getUpdates request»
    → Бот уже запущен где-то ещё (на старом компьютере или во втором окне).

«Не удалось записать в Excel ... занят другим процессом»
    → Закройте bot_data.xlsx в Excel.
